# MySchool Checks: Επέκταση Chrome

**Αυτοματοποιημένοι έλεγχοι, αναφορές και ενέργειες για την πλατφόρμα MySchool, απευθείας μέσα στον browser.**

Δημιουργία: **Μιχάλης Κατσιρντάκης**, Διεύθυνση Π.Ε. Ανατολικής Θεσσαλονίκης

> Το repository είναι παρουσίαση του έργου. Ο κώδικας της επέκτασης είναι ιδιωτικός.

---

## Τι είναι

Επέκταση για Google Chrome που βοηθά τις Διευθύνσεις Εκπαίδευσης να ελέγχουν την ορθότητα των δεδομένων στο **MySchool**, να βγάζουν αναφορές και να κάνουν μαζικές καταχωρήσεις.

Δουλεύει **μέσα στη σύνδεση MySchool που έχει ήδη ανοιχτή ο χρήστης**: δεν ζητά και δεν αποθηκεύει κωδικούς. Κατεβάζει τις απαραίτητες καταστάσεις, κάνει τους ελέγχους, βγάζει αρχεία Excel και, όπου χρειάζεται, στέλνει εξατομικευμένο email σε κάθε σχολείο.

Είναι η εξέλιξη της desktop εφαρμογής [MySchool Checks](https://github.com/MichalisKat/MySchoolChecks), την οποία αντικατέστησε.

## Τι κάνει

### 🗂 Έλεγχοι (Α1–Α13)
| | |
|---|---|
| **Α1** | Επιβεβαίωση δεδομένων |
| **Α2 / Α2Ι** | Διαφορές στοιχείων (και για την Ιδιωτική εκπαίδευση) |
| **Α3** | Αρνητικά υπόλοιπα ωραρίου |
| **Α4** | Άδειες άνευ αποδοχών & παρόντες |
| **Α5** | Παρόντες σε μακροχρόνια άδεια |
| **Α6** | Μακροχρόνια απουσία χωρίς άδεια |
| **Α7** | Ελλιπή στοιχεία ανάληψης υπηρεσίας |
| **Α8** | Διοικητικό έργο |
| **Α9Α / Α9Β** | Υπόλοιπα ωραρίου & επιβεβαίωσης |
| **Α10 / Α11** | Τμήματα Γενικής Παιδείας & Ολοημέρου |
| **Α12** | Έλεγχος Ε.Ε.Α. |
| **Α13** | Λεπτομέρειες ωραρίου (συμπληρώσεις) |

### 📊 Αναφορές (Β1–Β6)
- **Β1** Ενημερωτικό
- **Β2** Σχολικές Μονάδες, με αποστολή ανά Δήμο
- **Β3 / Β4** Εκπαιδευτικοί ανά Ειδικότητα, με αποστολή στους Συμβούλους Εκπαίδευσης
- **Β5** Ανοιχτά Δεδομένα
- **Β6 Συνολική Αναφορά Σχολείων:** εβδομαδιαία εξατομικευμένη ενημέρωση κάθε σχολείου για τις εκκρεμότητές του, με σύγκριση με την προηγούμενη εβδομάδα (τι νέο προέκυψε, τι διορθώθηκε) και σύστημα επιβράβευσης ⭐ για τα σχολεία χωρίς εκκρεμότητες

### 🏛 Ενέργειες (Ε1–Ε8)
Μαζικές καταχωρήσεις στο MySchool από αρχείο Excel: τοποθετήσεις, τερματισμοί τοποθετήσεων, αλλαγή λειτουργικότητας, λεπτομέρειες ωραρίου, απουσίες σε οργανική, μεταβολή ωρών τοποθέτησης. Όλες περνούν πρώτα από **προέλεγχο μόνο ανάγνωσης**, εφαρμόζονται μία-μία με επιβεβαίωση και δυνατότητα διακοπής, και βγάζουν Excel αποτελεσμάτων.

## Ασφάλεια

- **Χωρίς κωδικούς MySchool:** η επέκταση χρησιμοποιεί τη σύνδεση που έχει ήδη κάνει ο χρήστης.
- **Ασφαλής αποστολή email:** η «Αποστολή» ξεκλειδώνει μόνο μετά από επιτυχημένη «Δοκιμή σε εμένα», ξανακλειδώνει σε κάθε αλλαγή κειμένου, και όσα στάλθηκαν δεν ξαναστέλνονται.
- **Τα δεδομένα μένουν τοπικά:** τίποτα δεν στέλνεται σε τρίτους. Τα email φεύγουν από τον λογαριασμό sch.gr του χρήστη, με αντίγραφο στα Απεσταλμένα.
- **Αυτόματα αντίγραφα ασφαλείας** όλων των ρυθμίσεων και του ιστορικού.

## Από τη desktop εφαρμογή στην επέκταση

| | Desktop εφαρμογή | Επέκταση Chrome |
|---|---|---|
| **Σύνδεση στο MySchool** | Αποθήκευση κωδικών | Χωρίς κωδικούς |
| **Σταθερότητα** | Εξάρτηση από Selenium / ChromeDriver | Τρέχει μέσα στον ίδιο τον browser |
| **Ταχύτητα** | Ξεχωριστός browser και αυτοματοποίηση κλικ | Άμεση πρόσβαση στις σελίδες του MySchool |
| **Λειτουργίες** | Έλεγχοι και αναφορές | + μαζικές ενέργειες, Β6 με ιστορικό και ⭐ |

Κάθε έλεγχος μεταφέρθηκε από τη desktop εφαρμογή και **συγκρίθηκε ένα-προς-ένα** στα ίδια αρχεία πριν αποσυρθεί η desktop.

## Τεχνολογία

Chrome Extension (Manifest V3) · JavaScript · SheetJS για τα Excel · βοηθητικό πρόγραμμα Python για την αποστολή email (SMTP sch.gr) μέσω native messaging.
